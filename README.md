# Chapter 1 Writing Stars — Spot the Excellent Answer!

A mobile-friendly, static comparison game for PUSL2048 Level 5 students. Uses the university entrepreneurship example.

## Game

For each of five Chapter 1 components, students compare basic and very good writing, choose the stronger version, and receive encouraging feedback explaining the marking criteria. Correct choices earn stars and a final Fabulous Research Writer award. The order of the two answers alternates to discourage guessing by position.

## Publish to GitHub Pages

1. Create a **public** repository named `chapter1-writing-stars`.
2. Upload `index.html`, `style.css`, `app.js`, and `README.md` **directly to the root** (not a nested folder).
3. Under **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. Once deployment completes, the site should appear at `https://YOUR-USERNAME.github.io/chapter1-writing-stars/`.
5. Test all five challenges on a phone before sharing.

## Teaching notes

The examples illustrate rubric levels; they are not actual assessed student submissions or a guarantee of a particular grade. Any factual claims about a university or prior literature should be supported by genuine sources. The game rewards recognition of strong writing, not a formal mark. Progress is stored in each browser locally, not sent to the teacher. No server or sign-in is needed.
